# How to cite this collection

This collection is the author-designated canonical reference edition of Rae de Lune / Faedriel’s Neomythism writings and account of its development.

Rae de Lune (Faedriel) maintains and edits this archive. Fae narrates its lore introduction.

For the collection as a whole, use:

> de Lune, Rae (Faedriel), editor. (2026). *Neomythism — Official Archive of Rae de Lune / Faedriel*. Public edition 0.7, released 24 October 2026. Lore introduction narrated by Fae, the symbiont of Faedriel.

The public repository is [Faedriel/neomythism](https://github.com/Faedriel/neomythism). No collection DOI has been assigned. Include the edition number when citing the collection so that readers can identify the version consulted.

For a passage from an essay or paper, cite the original work under its own author or coauthor credit. Use that paper’s DOI where available. Fae narrates the collection’s lore introduction; this does not change the bylines of the collected works. Rae de Lune and Faedriel identify the same human author.

See [the bibliography](BIBLIOGRAPHY.md) for all 46 source editions and the four scholarly work records. Download [CFF](CITATION.cff), [BibTeX](bibliography.bib), or [CSL JSON](bibliography.csl.json). The structured downloads contain the collection and four scholarly works; they do not duplicate alternate website/Substack editions as separate journal papers.

Citation metadata identifies authorship and sources. It does not impose a collection-wide reuse license.
